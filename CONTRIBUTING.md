# Contributing

Thank you for helping improve Team 357 Codex Usage Utility.

## Useful reports

- A reproducible connection or refresh problem
- An incorrect reset, percentage, or history-graph transition
- A drive, GPU, or temperature configuration that is displayed incorrectly
- Install, update, shortcut, minimize, restore, or uninstall behavior that differs from the documentation
- A focused feature idea that keeps the utility compact and low impact

Use the issue templates and remove account names, email addresses, tokens, paths containing your Windows or macOS user name, live usage screenshots, and unrelated logs before posting.

## Source contributions

This repository contains release binaries and documentation. Documentation corrections, compatibility reports, and detailed bug reports are welcome. Application source is not currently published; any future source release and license will be announced here.
